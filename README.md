# Stack Game

A simple browser-based stacking game where you stack moving blocks on top of each other to score points.

## 🎮 How to Play

  **Click**, **tap**, or **press SPACE** to start the game.  
  
  Blocks move horizontally — drop them so they land on the stack.  
  
  If a block misses, the game ends.  
  
  Tap/click to restart and try to beat your score.
